The problem asks you to read an integer n from standard input and print all integers from 1 through n consecutively, without spaces or separators.

Problem Statement

The included code stub will read an integer n from STDIN.

Without using any string methods, try to print:

123...n

Here, 123...n represents the consecutive values from 1 to n.\


if __name__ == '__main__':
    n = int(input())
    result = ''
    for i in range(1,n+1):
        #direct approach
        # print(i,end="")
        # loop wise
        result += str(i)
    print(result)
