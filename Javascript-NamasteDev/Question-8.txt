Problem

Given an array arr of valid finite numbers, return the sum of all elements in the array.

Examples

Example 1

Input:  arr = [1, 2, 3]
Output: 6

Example 2

Input:  arr = [5]
Output: 5

Example 3

Input:  arr = []
Output: 0

Example 4

Input:  arr = [-1, 5, -4]
Output: 0
Constraints
Input is always a valid array.
All elements are guaranteed to be finite numbers.
No need to validate invalid inputs.
