CryptoRank Exchange

You need to build a React application called CryptoRank Exchange that estimates how many cryptocurrency coins a user can receive based on an entered amount of fiat currency.

Requirements
1. Input

Provide an input field where the user can enter the amount of money they want to exchange.

The amount:

Is mandatory.
Must be at least $0.01.
Must not exceed the user's available balance.
2. Cryptocurrency table

Display a table containing:

Cryptocurrency	Exchange Rate	Number of Coins
Cryptocurrency name	Rate	Calculated amount

The table should update dynamically whenever the entered amount changes.

3. Initial state

When the application loads:

Input should be empty.
No error message should be displayed.
Number of Coins should display:
0.00000000

for every cryptocurrency.

4. Conversion calculation

For a valid amount:

Number of Coins = Amount × Exchange Rate

The result should be rounded to 8 decimal places.

For example, if:

Amount = 100
Exchange Rate = 0.12345678

then:

Number of Coins = 12.34567800
5. Invalid amounts

For an invalid amount, the Number of Coins column should display:

n/a
Error messages
Empty input

If the user clears the input:

Amount cannot be empty

Amount below minimum

If the amount is less than $0.01, it should be considered invalid.

Amount exceeds balance

If the amount exceeds the available balance, display:

Amount cannot exceed the available balance





import React from "react";
import "./App.css";
import "h8k-components";
import Main from "./components/Main";

const title = "Cryptocurrency Exchange";

const App = () => {
  return (
    <div>
      <h8k-navbar header={title}></h8k-navbar>
      <Main />
    </div>
  );
};

export default App;





import React, { useState } from "react";
import Table from "./Table";

function Main() {
  const [amount, setAmount] = useState('')
  const [isFirstLoad, setIsFirstLoad] = useState(true);
  const handleInputChange = (e) => {
    const amount = Number(e.target.value);
    setAmount(amount)
    setIsFirstLoad(false)
  }
  return (
    <div className="layout-column align-items-center mx-auto">
      <h1>CryptoRank Exchange</h1>
      <section>
        <div className="card-text layout-column align-items-center mt-12 px-8 flex text-center">
          <label>
            I want to exchange $ <input className="w-10" data-testid="amount-input" required type="number" placeholder="USD" value={amount} onChange={handleInputChange} /> of my $
            <span>17042.67</span>:
          </label>
          {!isFirstLoad && amount == '' && (
            <p data-testid="error" className="form-hint error-text mt-3 pl-0 ml-0">
              {"Amount cannot be empty"}
            </p>
          )}
          {!isFirstLoad && amount > 17042.67 && (
            <p data-testid="error" className="form-hint error-text mt-3 pl-0 ml-0">
              {"Amount cannot exceed the available balance"}
            </p>
          )}
          {!isFirstLoad && amount < 0 && (
            <p data-testid="error" className="form-hint error-text mt-3 pl-0 ml-0">
              {"Amount cannot be less than $0.01"}
            </p>
          )}

          {/* The errors can be Amount cannot be empty /be less than $0.01/exceed the available balance */}
        </div>
      </section>
      <Table amount={amount} isFirstLoad={isFirstLoad} />
    </div>
  );
}

export default Main;




import React from "react";
import { cryptocurrencyList } from "../cryptocurrency-list";

function Table({ amount, isFirstLoad }) {
  return (
    <div className="card card-text mt-10 mx-4">
      <table className="mb-0">
        <thead>
          <tr>
            <th>Cryptocurrency</th>
            <th>Exchange Rate</th>
            <th>Number of Coins</th>
          </tr>
        </thead>
        <tbody data-testid="exchange-data">
          {cryptocurrencyList.map((currency) => (
            <tr key={currency.code}>
              <td>{currency.name}</td>
              <td>1 USD = {currency.rate}</td>
              {isFirstLoad && <td>0.00000000</td>}
              {!isFirstLoad && <td>{amount >= 0.01 && amount <= 17042.67 ? amount * currency.rate : "n/a"}</td>}
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}

export default Table;
